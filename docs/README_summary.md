# 小松 優基 — 職務経歴 要約版

> 事業創出を担えるエンジニア。テックリード × PdM の二足。2026年5月起業予定。

安定期・グロース期・新規事業の各フェーズを横断して経験。
現在は3Sunnyでチーフエンジニア兼PdM主務として、医療ドメインの新規事業をPoCから商品化まで一気通貫で推進中。
並行して2026年5月に自社を起業予定。
事業課題の解決と組織を整える力で、長期に価値を出す働き方を志向。

## 強み

- **フェーズ横断の経験**：安定期、グロース期、新規事業の各フェーズを経験してきた。
- **幅広い技術スタック**：フロントエンド・バックエンド・インフラを網羅的に担当してきた。
- **開発プロセス・体制を整える力**：開発プロセス改善、CI/CD導入、リリースプロセス効率化など、開発体制の向上に継続的に取り組んできた。
- **PdM × エンジニアの橋渡し**：施策の仮説検証、ユーザーインタビュー、プロダクトの未来像と現在の課題からのリソース配分など、業務範囲が広い。
