# 小松 優基 — 職務経歴 要約版

> 事業創出を担えるエンジニア。テックリード × PdM の二足。2026年5月起業予定。

安定期・グロース期・新規事業の各フェーズを横断して経験。
現在は3Sunnyでチーフエンジニア兼PdM主務として、医療ドメインの新規事業をPoCから商品化まで一気通貫で推進中。
並行して2026年5月に自社を起業予定。
事業課題の解決と組織を整える力で、長期に価値を出す働き方を志向。

## 強み

- **事業フェーズに応じた開発判断の切り替え**：フェーズに応じて技術投資の粒度を切り替える。
安定期：仕様互換性と負債解消、新規事業：PoC速度と検証コスト、グロース局面：計測・運用設計、という重み付けを使い分けてきた。
- **ヒアリングから本番リリース・改善戦略まで一人で通す E2E 実行力**：事業仮説の検証から要件定義・設計・開発リード・リリース実作業・モニタリング・改善方針策定まで、一気通貫で担当。
組織を巻き込みつつ全工程に自分で踏み込んできた。
スコープが広いだけでなく、各レイヤーで適切な深さに踏み込める。
- **経営目標とユーザー体験をロジックチェーンで接続する戦略策定力**：売上目標 → 体験定義 → 阻害要因分析 → 成果優先順位 → 大方針 → 施策 → 技術設計を1人で連結。
批判的自己評価としてプランB併記まで踏み込む戦略構築のスタイル。
経営層への段階的承認フローまで設計し、意思決定サポートまで完遂してきた。
- **「やらない」判断を組織知に変える設計力**：技術選定で採用するものより、却下するものの理由を残す。
後続の議論コスト低減を狙った組織文化として定着させてきた。
早すぎる抽象化を避け、現時点で必要のない共通化は明示的に保留する。
共通UIコンポーネント化、UseCase層追加、Next.js移行などの「やらない判断」をADRとして継続的に残してきた。
- **ジュニアでも追える設計を、技術選定段階から組み込む育成設計力**：技術選定そのものを学習機会として設計し、ジュニアでも追える形に翻訳する。
テスト・OOP・DDD未経験のジュニアを、Specificationパターン・型安全モックテスト・次期テックリードまで段階的に引き上げた。
マルチフロント技術選定を意図的に分離し、中間レベル → 本来到達レベルと段階的に上がる学習ステップとして組み込んだ。
